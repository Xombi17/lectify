# End-to-End Flow (Production MVP)

Teacher:
1) Start recording
2) Stop recording → upload audio
3) Lecture queued for processing

System:
1) Store audio
2) Queue transcription
3) Clean transcript
4) Tag exam-relevant info
5) Generate notes/quiz/flashcards
6) Publish to student dashboard

Student:
1) Scan QR to join class
2) View notes/search/quiz/flashcards by end of day

Admin:
1) Configure academic structure
2) Assign teachers
3) Monitor processing status
