# Product Spec (Production MVP)

## 1) Product Summary
Lectify is a production-grade lecture intelligence platform that captures full lecture sessions and turns them into structured study assets (notes, quizzes, flashcards, search) by end of day.

## 2) MVP Outcomes
- Admin configures academic hierarchy (year/branch/semester/subject/division).
- Teachers record lectures (mic/upload) and stop to trigger upload.
- Queue-driven AI pipeline produces notes and assets.
- Students access study materials by end of day.
- QR-based class enrollment.

## 3) Core Roles
- Admin: configure hierarchy, assign teachers.
- Teacher: record/upload, review, publish.
- Student: study notes, quiz, flashcards, search.

## 4) MVP Features
- Recording upload
- Transcription
- Transcript cleaning
- Exam importance tagging
- Summary + smart notes
- Quiz + flashcards
- Search
- Student dashboard
- QR enrollment

## 5) Non-Goals (MVP)
- Live transcription
- Knowledge graph UI
- Real-time collaboration
- AI avatars
