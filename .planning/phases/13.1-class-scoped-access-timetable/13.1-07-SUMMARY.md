# Plan 13.1-07 Summary: Realistic College Seed Fixture & Cross-Class Isolation Suite

## Overview
Built a production-grade realistic college fixture simulating Apex Institute of Technology across 4 engineering branches (COMPS, CSE, ELEC, MECH), 4 years, semesters, divisions (A, B, C), subjects (OS, DBMS, Networks, DSA), classes, users (admins, teachers, students), timetable slots, and published lectures.
Accompanied by a 9-scenario cross-class isolation test suite rigorously asserting zero leakage and strict fail-closed enforcement across the entire platform.

## Key Changes
1. **Realistic College Seed Fixture (`backend/fixtures/college_seed.py`)**:
   - Creates full academic tree, accounts, enrollments, teacher assignments, timetable slots, and sample lectures with unique concepts for search testing.
2. **SQLite StaticPool (`backend/core/sql_db.py`)**:
   - Added `StaticPool` for in-memory SQLite test databases (`sqlite+aiosqlite:///:memory:`) so async tasks and worker threads share the single in-memory database catalog.
3. **Comprehensive Isolation Test Suite (`backend/tests/test_cross_class_isolation.py`)**:
   - `test_student_cannot_fetch_other_class_lecture_detail`: Verifies fail-closed HTTP 404.
   - `test_student_cannot_stream_other_class_audio`: Verifies HTTP 404 preventing unauthorized audio streaming.
   - `test_student_cannot_view_other_class_study_materials`: Verifies HTTP 404 for PDF export, bookmark listing, bookmark creation, and flashcard review/state.
   - `test_student_cannot_attempt_other_class_quiz`: Verifies HTTP 404 preventing unauthorized quiz submissions.
   - `test_student_cannot_query_or_post_other_class_chat`: Verifies HTTP 404 on chat queries and history retrieval.
   - `test_student_search_filters_out_other_class_lectures`: Verifies zero search result leakage across divisions.
   - `test_student_cannot_view_other_class_timetable`: Verifies schedule visibility isolated to enrolled classes.
   - `test_teacher_cannot_upload_lecture_to_unassigned_class`: Verifies HTTP 403 on unassigned upload, HTTP 202 on assigned upload.
   - `test_teacher_cannot_publish_lecture_for_unassigned_class`: Verifies publishing restriction for unassigned classes.
